# Instructions for Claude

## Never post on the user's behalf without explicit approval

Do not post, comment, reply, or otherwise write anything to GitHub (issue
comments, PR comments/reviews, discussions, etc.) on the user's behalf
unless the user has explicitly approved that specific post first.

- This applies regardless of whether the content includes any
  attribution/signature or not — the issue is posting without approval,
  not the signature itself.
- "The user asked me to look into/fix issues" is NOT approval to post
  comments on those issues. Investigating, fixing, and commenting are
  separate actions — each outward-facing post needs its own explicit go-ahead.
- If you think a comment would be useful, draft it and show it to the user
  first, then wait for a clear yes before posting.
- This applies to every GitHub write action (comments, replies, issue/PR
  edits, etc.), not just issue comments specifically.
